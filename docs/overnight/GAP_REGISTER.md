# Nexora Platform — Overnight Gap Register

This register is the single source of truth for all identified defects, security vulnerabilities, schema deficiencies, UX inconsistencies, and missing capabilities across the Nexora platform.

| ID         | Area      | Gap Description                                                                                                                                                                                               | Severity     | Fix Plan                                                                                                                                                                            | Status           |
| ---------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| **GAP-01** | Data/SQL  | `OutboxMessage` missing structured status enum (`Pending`, `Processing`, `Processed`, `DeadLetter`, `DeliveryOutcomeUnknown`), retry backoff timestamp (`NextAttemptAtUtc`), and bounded delivery protection. | **CRITICAL** | Update `OutboxMessage.cs`, entity mapping in `AppDbContext.cs`, add `NextAttemptAtUtc` calculation, and migration. Update `OutboxProcessor` to claim based on status + time window. | Closed (Phase 2) |
| **GAP-02** | Data/SQL  | Missing `RowVersion` optimistic concurrency tokens on editable domain entities (`Leads`, `Clients`, `TaskItems`, `BlogPosts`, `FormDefinitions`, `EmailTemplates`).                                           | **CRITICAL** | Add `byte[] RowVersion` / `[Timestamp]` to domain entities and configure `b.Property(x => x.Version).IsRowVersion()` in `AppDbContext.cs`.                                          | Closed (Phase 2) |
| **GAP-03** | Data/SQL  | `PipelineStages` missing unique composite constraints on `(Category, StageKey)` and `(Category, Value)`, allowing duplicate conflicting stages.                                                               | **HIGH**     | Add `.HasIndex(s => new { s.Category, s.StageKey }).IsUnique()` and `.HasIndex(s => new { s.Category, s.Value }).IsUnique()` in EF Core configuration and migration.                | Closed (Phase 2) |
| **GAP-04** | Data/SQL  | `NavigationMenus` index on `(Key, RegionCode)` fails SQL Server multi-null semantics for default global menus (`RegionCode == null`).                                                                         | **HIGH**     | Replace with filtered unique index on `Key` WHERE `RegionCode IS NULL` and `(Key, RegionCode)` WHERE `RegionCode IS NOT NULL`.                                                      | Closed (Phase 2) |
| **GAP-05** | Data/SQL  | `SiteSettings.SectionVisibilityJson` missing SQL Server JSON check constraint and default `{}`.                                                                                                               | **MEDIUM**   | Add check constraint `CK_SiteSettings_SectionVisibility_Json` enforcing `ISJSON([SectionVisibilityJson]) = 1` and default `"{}"`.                                                   | Closed (Phase 2) |
| **GAP-06** | Security  | SMTP password in `SiteSettings` is stored as plaintext in database.                                                                                                                                           | **CRITICAL** | Encrypt `SmtpPassword` using ASP.NET Core Data Protection (`IDataProtector`) before persisting to database, and decrypt on retrieval.                                               | Closed (Phase 2) |
| **GAP-07** | CMS       | Pages deletion endpoint missing; when deleting, cascade delete would permanently destroy version history and audit trail.                                                                                     | **HIGH**     | Add `ArchivePageAsync` / `DELETE /pages/{id}` that sets `Status = PageStatus.Archived` and soft-deletes, preserving PageVersions.                                                   | Closed (Phase 5) |
| **GAP-08** | CMS       | Preview tokens stored in plaintext in database instead of cryptographic SHA-256 hash.                                                                                                                         | **HIGH**     | Hash preview token with SHA-256 before storage; query using hashed token to prevent DB leak compromising unpublished content.                                                       | Closed (Phase 2) |
| **GAP-09** | CMS       | Dynamic sitemap (`sitemap.xml`) and robots generator (`robots.txt`) in `apps/website` need dynamic published page querying from backend CMS API.                                                              | **HIGH**     | Update `apps/website/src/app/sitemap.ts` and `robots.ts` to query `getCmsPages()` and include published CMS slugs dynamically.                                                      | Closed (Phase 4) |
| **GAP-10** | Website   | Section visibility configuration (`SiteSettings.SectionVisibilityJson`) is not respected by `page.tsx` rendering loop.                                                                                        | **HIGH**     | Connect website page renderer and block filters to `siteSettings.sectionVisibility` so admin toggles immediately hide/show sections.                                                | Closed (Phase 4) |
| **GAP-11** | Website   | Missing full suite of marketing block types: `ComparisonTable`, `RoiCalculator`, `BookingEmbed` (Cal.com / Calendly allowlisted), `ProcessSteps`, `Timeline`, `TeamGrid`.                                     | **HIGH**     | Implement clean, responsive component implementations in `apps/website/src/components/blocks/` with zero hardcoded copy.                                                            | Closed (Phase 4) |
| **GAP-12** | Admin UX  | Unsaved changes confirmation guard missing on CMS `PageEditorPage.tsx` and `SettingsPage.tsx`.                                                                                                                | **MEDIUM**   | Add dirty-state tracking with `useBeforeUnload` / React router blocking confirmation dialog before navigating away.                                                                 | Closed (Phase 4) |
| **GAP-13** | Admin UX  | Global top bar search input is a static placeholder and does not filter resources or provide quick command navigation.                                                                                        | **MEDIUM**   | Implement quick command palette / search dropdown that filters Pages, Leads, Clients, and Settings.                                                                                 | Closed (Phase 5) |
| **GAP-14** | Admin UX  | Notification bell in header has no interactive drawer to view system events, lead alerts, or outbox failures.                                                                                                 | **MEDIUM**   | Add notification slide-over drawer connected to recent audit logs and unread leads.                                                                                                 | Closed (Phase 5) |
