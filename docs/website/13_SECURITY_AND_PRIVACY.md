## 1. Security Headers & Content Security Policy (CSP)

## 2. Inbound Form & Anti-Abuse Defenses

1. **Honeypot Trap:** Hidden text input (`website_url_hp`) with zero tab-index and CSS invisibility. If populated, the request is flagged as a bot submission and rejected silently.
2. **Time-Trap Token:** Cryptographically signed timestamp token generated by the server. Submissions occurring in under 3.0 seconds (superhuman bot speed) or older than 24 hours are blocked.
3. **Idempotency Keys:** Every form render generates a unique `crypto.randomUUID()`. Submissions sharing the same key within a 15-minute window return the existing reference number without creating duplicate database leads.
4. **Rate Limiting:** IP-level throttling limits submissions to a maximum of 5 requests per 10 minutes per IP address.

---

## 3. Privacy Compliance (India DPDP Act 2023 & US Standards)

1. **Explicit Consent Checkbox:** Required on all lead forms. Users must opt-in with full disclosure of data usage.
2. **Consent Wording Versioning:** The exact consent statement version (e.g., `v1.2-web`) is recorded alongside the lead record for regulatory audits.
3. **Cookie Banner & Revocation:** Categorized cookie consent banner storing preferences in `localStorage` (`nexora_cookie_consent`). A persistent link in the footer allows visitors to modify or withdraw consent at any time.
4. **Data Retention:** Inactive lead records older than 24 months without active engagement are scheduled for cryptographic erasure or anonymization.
